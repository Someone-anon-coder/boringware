## How it's built

A plain static site, generated by `build.py` from Markdown, with no JavaScript and no Pages
Functions. Hosted on Cloudflare Pages (direct upload).

```
content/site.toml        site settings and every product's facts (name, links, price, features)
content/pages/*.md       About, Privacy
content/articles/*.md    articles; _TEMPLATE.md shows the header fields and the article shape
static/                  CSS, images, _headers; copied as-is
tools/make_images.py     regenerates the favicon and the default social card
build.py                 builds dist/ and checks links, alt text and article headers
deploy.sh                build + upload to Cloudflare Pages
```

Pages built: home, `/link-migrator/`, `/splitmark/`, `/blog/` and one page per article,
`/about/`, `/privacy/`, `/links/` (for Instagram and Facebook bios), `/404.html`,
`sitemap.xml`, `robots.txt`, `feed.xml` (Atom). Every page has a canonical URL, Open Graph tags
and schema.org data (Organization, SoftwareApplication, BlogPosting, BreadcrumbList).

## Common tasks

```bash
pip install markdown                 # the only dependency (or: uv run --with markdown python build.py)
python3 build.py                     # build what is published today into dist/
python3 build.py --drafts            # preview drafts and future-dated articles (noindexed; never deploy)
python3 -m http.server -d dist 8000  # look at it on http://localhost:8000
./deploy.sh                          # build and publish
```

**Add an article:** copy `content/articles/_TEMPLATE.md` to `content/articles/<slug>.md`, fill in
the header, write, preview with `--drafts`, commit, then run `./deploy.sh` on or after its date.
An article dated in the future stays off the live site until a deploy on or after that day.
Afterwards, request indexing for the new URL in Google Search Console.

**Change a product's price or links:** edit `content/site.toml`, then build and deploy.
