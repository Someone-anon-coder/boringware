BoringWare makes small Windows tools for the tedious jobs that land on office desks: the hour
spent fixing broken spreadsheet links after a server move, or the afternoon spent splitting and
renaming a month of invoices by hand. It is run by Aayush Choudhary, a software developer.

## Why boring software

The jobs nobody wants are usually the ones nobody has built a good tool for. They are too small
for enterprise software and too fiddly for a quick macro, so people do them by hand, every month,
and make mistakes when they are tired. A tool that does one of those jobs properly is worth more to
the person stuck with it than another feature in a big suite.

So every BoringWare tool follows the same rules:

- **One job, done properly.** Each tool solves a single, specific problem, and its limits are
  written down where you can read them before you buy.
- **Your files stay on your PC.** Nothing is uploaded. The only time a tool connects to the
  internet is to check its licence key.
- **Originals are left alone.** Results are written as new files, and nothing is replaced
  without asking you first.
- **Try it, then pay once.** Every tool can be tried on your own files for free. Licences are a
  one-time price, with no subscription needed.
- **No AI guesswork.** The tools follow rules you can see and change, so the same input always
  gives the same result.

## The tools

- [Link Migrator](/link-migrator/) finds and fixes every broken Excel, Word and PowerPoint link
  after a file server or SharePoint move.
- [Splitmark](/splitmark/) splits one combined PDF of invoices, statements or payslips into
  separate files, named from their own text.
